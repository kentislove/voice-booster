# 分頁音量放大神器 - 第二版（v2）雙核心旗艦版說明文件

## 一、 版本基本資訊
- **版本號**：第二版（v2.0.0）
- **規範版本**：谷歌瀏覽器擴充功能第三版規範（Manifest V3）
- **發布日期**：2026 年 10 月 7 日

---

## 二、 本次版本重大變更與升級重點

1. **核心痛點修復：完美突破受版權保護影音平台（如網飛 Netflix）的限制**
   - **問題回顧**：第一版在網飛播放時，因瀏覽器底層數位版權管理防側錄機制，導致分頁捕捉被拒絕並彈出受保護頁面警告。
   - **本版解法**：研發「雙核心混合引擎」，加入了專門深入網頁內部的「網頁元素注入核心」，直接找到影片標籤進行就地放大，不再受限於外層分頁側錄鎖！

2. **新增「雙核心智慧切換」使用者介面**
   - **一般全域模式**：適用於優管、社群影音、線上廣播等一般網頁，捕捉整頁聲音。
   - **網飛相容模式**：專門針對網飛、迪士尼等嚴格加密串流網站，就地放大播放器聲音。
   - **智慧自動偵測**：若目前網址為網飛，彈出選單會自動優先推薦網飛模式；若在一般模式被系統阻擋，也會自動智慧切換並提示使用者！

3. **系統架構新增模組**
   - 新增 `content_injector.js`：專職負責網頁內部的影片元件音訊節點綁定與動態追蹤。
   - 擴充 `manifest.json`：增列腳本注入授權與全網域主機權限，保證能順暢在各串流平台運作。

---

## 三、 在瀏覽器中載入與測試步驟

1. 打開谷歌瀏覽器，在網址列輸入 `chrome://extensions/` 並進入。
2. 確保右上角「開發人員模式」處於「開啟」狀態。
3. 點擊「載入未封裝項目」。
4. 選擇最新的測試複本資料夾路徑：`f:\雜記\Chrome Extension\Voice Booster\v2_test`。
5. （若先前已有載入 v1，可先在擴充功能清單中將 v1 關閉或移除，避免混淆）。
6. 打開網飛（Netflix）並開始播放影片，點開擴充功能圖示，系統會自動選取「網飛相容模式」，拉動滑桿即可暢快享受大音量！
